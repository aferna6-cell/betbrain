## Features Built

   captures consensus odds for pending picks whose games start within 30 min. Cache-only.
2. **Custom signal builder** — 12 condition types (odds variance, book count, spread/total
   thresholds, favorite detection), AND/OR logic, sport filter, localStorage persistence,
   5 preset rules. UI integrated in Signals page.
3. **EV decay tracker** — Analyzes odds history to measure how quickly market corrects
   +EV opportunities. Half-life, correction speed, decay percentage. UI in EV Scanner.
4. **Reverse line movement alerts** — Detects games where line moves against expected
   public action. Estimates public side from favorite bias, checks variance asymmetry.
   Strength classification. UI in Signals page.
5. **Portfolio risk gauge** — Analyzes open picks for sport concentration, correlated
   bets, large positions, heavy favorites. Risk score 0-100 with 5 levels. UI in Tools.
